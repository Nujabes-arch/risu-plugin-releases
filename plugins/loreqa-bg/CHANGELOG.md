# 캐논 가이드 변경 기록

## 0.3.2 — 2026-11-14

- 1차 모델 판단에 관계없이 BG 분석 전에 Exa 자료를 조회하고, 켜진 2차 검증을 매 분석마다 실행합니다.
- 2차 추가 Exa 조회를 별도 토글로 분리했습니다. 기본 OFF이며 1차 자료는 항상 검증에 전달합니다.
- 1차 Exa/2차 추가 Exa/BG 2차 검증 로그를 구분하고 도구명·HTTP 상태·결과 글자 수·설정/빈 결과 오류 및 생략 이유를 표시합니다.
- 1차 JSON 실패도 켜진 2차 검증으로 넘기며, 2차 JSON 실패 시 1차 보정을 검증 완료로 쓰지 않습니다.
- 기존 분석 간격·채팅 범위·저장 키·설치 ID·고정 업데이트 주소를 유지합니다. v0.3.1은 업데이트 버튼으로 받습니다.

문법·회귀 검사 56/56 및 실제 Edge의 가짜 API 호출 순서/토글/로그 검증 통과. 실제 사용자 호스트·실모델·Exa 실서버 호출은 미실행입니다.

## 0.3.1 — 2026-11-13 (첫 공개 개발판)

- 공개 업데이트 주소 추가. 기존 개발판은 한 번 같은 이름으로 교체 설치한 뒤 업데이트 버튼을 사용합니다.
- 표시 이름 캐논 가이드, 8개 상위 탭, 한곳에 모은 모드별 모델·추론 강도 설정.
- OpenAI 호환 모델 목록 조회·드롭다운, low/medium/high/xhigh/max 선택.
- LiteLLM Exa 검색만 노출하고 BG 요청에서 이전 native 웹검색 및 PDF 전송을 적용하지 않음.
- 선택한 프리셋에 덮어쓰기, 최근 60건의 호출·자료 내역, 실패 단계 수동 재시도.
- 내부 플러그인 ID와 저장 키 유지. v0.3.0 개발판 대비 기능 변경은 없고 업데이트 메타데이터와 버전만 추가.

로컬 회귀 검사 52개 통과, 문법 및 배포 검사 통과. 가짜 API를 사용한 실제 브라우저에서 UI와 503 뒤 수동 재시도를 검증했습니다.
실제 RisuAI/PocketRisu·LiteLLM/Exa 환경에서의 동작과 설치·업데이트·복구는 미검증입니다.
